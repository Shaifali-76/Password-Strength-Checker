# Password Analyzer

A web-based Password Analyzer that helps users evaluate the strength of their passwords in real time. The application provides instant feedback based on password length, character variety, and complexity, encouraging users to create stronger and more secure passwords.

## Features

<li> Real-time password strength analysis
<li> Password security evaluation based on:

  <li> Length
  <li> Uppercase letters
  <li> Lowercase letters
  <li> Numbers
  <li> Special characters
<li> Visual strength indicator
<li> Instant feedback for improving password security
<li> Responsive and user-friendly interface

## How It Works

The Password Analyzer checks the entered password against multiple security criteria and categorizes it as:

<li> Weak
<li> Moderate
<li> Strong

The analyzer evaluates:

<li> Password length
<li> Character diversity
<li> Complexity and randomness

Users receive immediate feedback to help create more secure passwords.

## 🛠️ Tech Stack

<li> HTML5
<li> CSS3
<li> JavaScript
  
## Objective

The goal of this project is to promote cybersecurity awareness by helping users understand the characteristics of strong passwords. It serves as a practical tool for improving password security and protecting online accounts from unauthorized access.
